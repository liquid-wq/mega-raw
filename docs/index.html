What it is

MEGA-RAW connects a physical Mega Drive, a Mega EverDrive and RetroAchievements. Achievements trigger from the actual console state while you play. The game itself is never touched.

How it works

A custom FPGA core inside the Mega EverDrive replaces the standard mapper. While you play, it hands the values the achievements need to your PC over USB, and MEGA-RAW checks the conditions there. Nothing is written back into the running game.

No ROM patch

Games run completely unmodified. No IPS file, no per-game database to maintain, and no two-megabyte size limit.

The cartridge names itself

The game is recognised by itself within seconds. Nothing to select, no collection folder to point at.

Live values

Only the values the achievement set actually needs are passed to the PC, every frame, while the game runs.

Its own save state menu

Replacing the cartridge mapper normally costs you the EverDrive's in-game menu. MEGA-RAW brings its own along instead, built from scratch: it saves the complete state of the console and puts it back exactly as it was. Start + Down opens it over the running game: CONTINUE, SAVE, LOAD, EXIT. Four slots per game, stored as files on the SD card, so they survive switching the console off.

Hardcore mode

Planned, not active yet

RetroAchievements only counts Hardcore unlocks from clients it has approved, and a client has to be publicly available for at least six months before it can be considered. MEGA-RAW is still too new for that, and it also has to pass a set of checks by RetroAchievements. Until then, every unlock is recorded as Softcore.

The groundwork is already in place: MEGA-RAW checks your setup before and during a session. Leave the EverDrive's in-game menu or cheats enabled and it says so and stays in Softcore.

Known limits

A few games cannot open the menu, and sound is not part of a save state. Some games use the Start button themselves — if Continue does not react in the menu, confirm with C instead.

Development and testing happen on the Mega EverDrive CORE. The PRO is supported experimentally since 1.3.0: achievements work there according to tester feedback, the in-game menu does not work on the PRO yet. Feedback is welcome as a GitHub Issue. Other models are untested.
