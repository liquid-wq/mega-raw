# Older versions (no longer maintained)

This folder keeps the earlier versions of MEGA-RAW for reference:

| Folder | Version |
|---|---|
| [`qt/`](qt/) | FPGA build, Qt version 1.x |
| [`cpp/`](cpp/) | patched build, C++ port |
| [`python/`](python/) | patched build, original Python version |

Please use the current version from the
[Releases](https://github.com/liquid-wq/mega-raw/releases).
